# 个人记忆记录：回执、修订与当前标签页恢复

> 以下保留历史包范围与验证口径。后续无正文遗忘核验入口及设备回显屏障见[增量契约](memory-forget-device-recovery.md)。

基线：`cf85d0ab2e883c469a6d9cc9ebea96b3621874ec`。此工作包只处理个人记忆记录的前端恢复与真实接口接线，不代表完整长期记忆系统、自动学习或生产部署已经完成。

## 本次行为

- 新建输入在发出请求前固定内容、账号和 UUID。等待及结果未知时输入不可改写；重复点击不再发出另一个创建请求。切换工作台分区后仍可使用原键核对。
- 创建请求只在取得有效回执后清除原输入；验证拒绝保留可编辑草稿。曾经结果未知的请求不会因为后来一次 4xx 而静默换键。原键遇到已修订记录的 409 时显示现有记录供查看，仍不另建；结束核对必须明确确认可能已保存、不会撤销服务器记录及再次保存可能重复。
- 同键返回遗忘墓碑时不重新创建。因为当前 410 响应没有可信记录 ID，先清空缓存列表再读取，不能凭原文猜测 ID，也不能在刷新失败后继续显示可能已更正后被遗忘的正文。
- 更正固定用户开始编辑时看到的修订号；较新的列表读取不会偷偷改变该修订。结果未知后先 GET 精确记录：内容及后一修订吻合则确认当前状态；版本未变才重试原更正；版本冲突则并列显示当前内容与草稿，用户明确选择以当前版本继续编辑，之后仍需再次保存。
- 未改内容不产生更正请求。原记录已不可用时，未修改的旧正文会清除；真正修改过的用户输入只作为可选中复制或放弃的本地草稿保留，不再提交到已不可用记录。
- 遗忘需确认。确认后本页立即隐藏正文，结果未知或拒绝时不伪报删除成功，也不因刷新旧列表而恢复正文。用户可以稍后核对并继续其他操作；仅记录 ID 的待核对入口保留在当前标签页，继续时仍指向同一条记录。
- 草稿、操作请求和核对入口只存在于当前标签页内存。无 localStorage、sessionStorage、IndexedDB 持久化正文；刷新、关闭标签页或退出账号不保证恢复。导航离开记忆面板后，未保存输入或待核对请求仍触发浏览器离开提示。
- 每个动作检查账号，所有异步请求检查账号和代次。对话框确认同时绑定账号代次、具体草稿/意图及仍挂载的面板，不清除后来的新输入。App 集成需在账号变更和退出时调用 cleanup；退出清理必须在首个 await 前，覆盖同 ID 的 A→B→A 会话。
- 写入开始与完成均使旧读取失效。加载较早记录重新核对已看过的前缀后整体替换，避免另一端删除前页记录后旧 offset 跳过末尾记录。
- 表单标签、明确的忙碌/错误/核对状态、键盘焦点恢复、列表入口和移动换行均已接线；位移动效遵从减少动画。诊断只使用现有 memory 类别和结果白名单，不记录输入、ID、错误消息或地址，不新增外部遥测。

## 接口依据与范围

后端 `routes/memory.js` 与 `services/memory/persistentMemory.js` 的实际契约：

- `/memory/store` 同账号同键同正文重放；同键不同当前正文返回 `IDEMPOTENCY_CONFLICT`；被遗忘记录返回 `MEMORY_FORGOTTEN`，不复活
- `/memory/:id/correct` 使用 `expectedRevision` 乐观并发，无独立更正幂等键；不能把断网后的 POST 简单重复发出
- `/memory/:id` 的 404、墓碑 410 和来源不可用 410 具有不同于写入成功的含义
- `/memory/:id/forget` 对已有记录重复遗忘返回同一 ID 的确认；不存在记录可返回404。前端不把404当成“正文清除已核验”

没有增加自动模型调用、自动群聊记忆注入、YouTrace 数据同步或后台数据采集。品牌、logo、LoginPage、SplashScreen、后端接口和共享协议保持不变。

当前后端列表仍是 offset 分页，不是跨页事务快照。前缀重读解决加载前发生的删除；在多页扫描期间并发增删仍需刷新，不能宣称已实现游标快照或多设备实时同步。遗忘本页正文不代表导出文件、第三方副本或整卷备份已经物理删除。

## 验证口径

- 新增/扩展前端回归用真实 MemoryCenter、Zustand、memory client 和 Axios 拦截器；HTTP adapter 为合成契约替身，动画为替身，DOM 为 happy-dom
- 覆盖创建丢回执、同键重放、创建后远端修订/遗忘、刷新失败仍清除遗忘正文、更正已提交/未提交/版本冲突、旧读取、账号代次、旧确认、新草稿、分页前删除、遗忘404后的非阻塞核对、原始正文/诊断隐私和离开提示
- 新增 Playwright 测试由既有 CI 的桌面与移动减少动画项目执行：真实 API 同键重放、修订冲突、丢更正回执、确认/取消遗忘、截图和窄屏溢出检查
- 本地只发现/编译 Playwright 测试，不运行浏览器。托管浏览器 loopback 访问已被策略拒绝，未使用其他浏览器或公共预览绕过

最终测试数量及结果应以此提交和集成提交实际运行记录为准；本地 DOM 和编译成功不等于真实浏览器视觉验收。
