# 群想 QunThink：任务连续性与工作台迭代

基线：2026-10-04 `main`，`ac69f6d6aa92b2b6f42166af26112bbdf3e9fd4c`。此文只记录本次实际改动，不替代《群想项目计划书》，也不把一个工作包称为平台全部完成。

## 产品边界

群想继续覆盖 AI 主导的交流、办公、创作、学习和娱乐，核心是目标、依据和可检查成果。YouTrace 的个人生活记录、日程、习惯、支出、日记和私人教练与之互补。两者独立使用，不共用数据库、登录状态或默认私人上下文。

本次没有实现跨产品同步。未来用户选择的交接需要：明确目的及目标账号/空间、字段允许列表、源对象与修订、幂等、权限撤销/删除传播、冲突处理和接收回执。不能把 YouTrace 的打卡或进度勾选当成群想目标的成果验收。

现有 Task 仍是文字生成任务；PostgreSQL 个人 Goal 仍是目标/验收基础件，`executionAvailable:false` 保持真实。Task→Goal 适配器需先解决跨存储的来源、版本与撤销一致性，不能用一个跳转按钮代替已完成的运行内核。

## 实际完成的链路

### 1. 从想法到可核验成果

- 任务输入按当前账号保留在当前标签页内存。切换工作台分区、离开并重新进入后能继续；关闭标签页或退出账号不承诺恢复。离开有未保存输入的标签页会触发浏览器离开提示。
- 场景模板不会静默覆盖已有输入；从消息带来的下一段内容会等待现有草稿先保存/清空。
- 任务列表可按工作/社交/娱乐、待处理/进行中和关键词筛选；无匹配有清除筛选入口。
- 草稿、来源变化、等待核验、生成失败、已确认成果分别呈现。删除放在展开详情中并需确认；复制、保存、核验有独立状态反馈。
- 主操作、行内状态、详情伸展和分区标记使用不同的动效；减少动画关闭位移动效。支持键盘焦点、可访问表单和窄屏。
- 仅挂载当前桌面或移动布局，避免隐藏页面重复轮询、重复表单和同名 DOM 标识。

### 2. 不重复调用，不假报取消

- 创建和生成均接受 UUID `Idempotency-Key`（兼容正文 `client_request_id`）。同内容同键重放；创建内容变化返回409；删除过的创建请求不会重新创建任务。
- 不确定的保存回执锁定原输入并复用原键核验；即使会话消失、模型配置改变或计划时间已过去，也仍可请求原回执。
- 生成前持久化派发记录。模型断线、超时、408/5xx、派发后的取消和回执保存失败均保守进入 `outcome_unknown`，不自动再次收费调用。
- 停止请求绑定 `cancel_request_id` 或 `run_id`。停止先于生成到达时持久保留该请求键的停止记录；后到的同键请求不能派发。旧停止不能取消新运行。
- 核验决定必须包含用户检查时的 `run_id`；弹窗打开后轮询到新运行也不会改变这次决定的对象。
- 真实 PgLow 会在读取时替换文档对象，派发门在模型目录重读后重新定位并检查任务，再写派发记录。已用真实 PostgreSQL 和本地协议服务回归。

### 3. 原始消息与账号隔离

- 消息转任务携带消息ID和所选修订时间；创建时检查修订，服务端计算来源摘要。源消息改变/撤回后，复制的旧提示、当前成果和历史成果不再对客户端返回，也不能再次送往模型。
- 历史每轮独立检查来源，不再用最新一轮来源代替全部历史。旧版摘要算法保留兼容标记，避免无变化的历史被误判过期。
- 请求在等待 CSRF 前固定 `X-Expected-User-Id`；服务端比较当前会话身份。另一个标签页切换账号时，旧页面的读和写均拒绝，而不是把新账号资料混入旧工作台。
- `ACCOUNT_CHANGED` 隐藏并清理旧界面，不替用户退出另一个账号的会话。明确成功的登录/注册回执为后续 bootstrap 绑定新身份，旧请求的迟到错误不能把新登录赶下线。
- 调整数据读取次序，较早的轮询不能覆盖较新的请求；未知生成的请求键直到终态回执才释放。

### 4. 可观察且不采集正文

工作台增加“运行记录”：只在当前标签页内存保存最多200条白名单类别、时间、耗时和结果。可暂停、清除或主动复制脱敏记录；不写浏览器持久存储、不上传、不含输入正文、错误消息、地址、密钥或用户ID。退出或账号更换时清空。

原 ErrorBoundary 的原始错误文字、堆栈、URL beacon 上报已移除。此改动不宣称仓库全部历史开发日志已经过隐私审计。系统监控在运行环境不允许枚举网卡时保留其他有效采样，并将网卡信息标为未知。
