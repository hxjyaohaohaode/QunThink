# 智能体创建弹窗：有界草稿保护

本次仅修改 `AgentCreateModal` 当前挂载期间的关闭行为。X、背景点击和焦点陷阱内的 Escape 使用同一处理函数：未完成创建且有输入时确认丢弃；取消确认保持步骤、文字、头像、模型选择、回复建议和问答；创建请求进行中不允许关闭；成功后关闭不再询问丢弃。真正关闭时统一重置模型选择。

这不是创建请求取消、未知回执恢复、跨页面持久草稿或后端创建验收。关闭成功的弹窗不撤销已经创建的智能体。现有 App 在关闭时卸载该组件；若未来改为保留组件挂载，应另验问题生成等异步回调跨关闭/重开的行为。

- `frontend/test/modalSafety.test.mjs` 检查现有焦点陷阱等通用行为；本次没有修改共享弹窗代码

- 截图、视频、trace 和证据边界附件只证明相应浏览器 UI 行为，不证明真实后端创建、模型质量或付费流程
